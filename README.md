# UTM Parameters Extraction and Ads Performance Analysis
#### Overview
This project contains an SQL query that combines data from Google Ads and Facebook Ads. The query aggregates key performance metrics, calculates conversion ratios, and handles null values properly. The goal is to merge data from multiple sources, calculate relevant metrics, and transform specific fields using expressions.

#### Data Sources
The SQL query utilizes the following tables:

* facebook_ads_basic_daily
* facebook_adset
* facebook_campaign
* google_ads_basic_daily
